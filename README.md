# Calculator Learn Project

### Run Lint Test
```bash
pnpm add -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin
pnpm add -D @eslint/js typescript-eslint globals
pnpm run lint
```
### Run Typecheck
```bash
pnpm run typecheck
```

### Run Playwright
```bash
pnpm add -D @playwright/test playwright wait-on http-server
```
start the backend
```bash
pnpm run build
pnpm run start
```
start the frontend server
```bash
pnpm run dev:page
```
build
```bash
pnpm build
```
run Playwright tests
```bash
pnpm test
```
